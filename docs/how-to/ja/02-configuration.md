# 設定と環境変数

**python-dotenv** により、リポジトリ直下の `.env` があれば読み込まれます。実際のキー名は `src/agent_factory.py` および LLM 実装側の `os.getenv(...)` を必ず確認してください。

## 推奨

- `.env` は **バージョン管理に含めない**。
- ローカルと本番で **同じ変数名** を使い、環境差による不具合を減らす。

## よくある変数（パターン）

- モデル API 用の **キー**
- プロバイダが受け付ける **モデル ID**
- `local` / `openai` / `grok` など OpenAI 互換系の **ベース URL**（必要な場合）

## トラブルシュート

1. 空キー・末尾スペース・余計な引用符がないか。
2. モデル文字列がアカウントで利用可能か。
3. OpenAI 互換ルートでは `lm_api_url` が必須で到達可能か。
