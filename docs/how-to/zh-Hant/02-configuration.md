# 設定與環境變數

專案透過 **python-dotenv** 讀取 `.env`（若存在）。實際變數名稱以 `src/agent_factory.py` 與 LLM 後端為準；本教學列出最常見、與 Gemini 預設路徑相關的項目。

## 建議做法

- 在專案根目錄建立 `.env`，**不要**把金鑰提交到版控。
- 本機開發時，用與正式環境相同的一組變數名稱，降低「本機可以、部署不行」的落差。

## 常見變數（範例名稱）

實際鍵名請對照程式碼中的 `os.getenv(...)`；常見模式包括：

- **API 金鑰**：供 `LMWrapper` / `GeminiWrapper` 呼叫遠端模型。
- **模型名稱**：例如對應 `GEMINI_MODEL` 或同等設定（依你專案版本而定）。
- **OpenAI 相容端點**：若 `provider` 為 `local` / `openai` / `grok` 類型，通常需要 base URL。

## 除錯檢查清單

1. 金鑰是否為空、是否有多餘空白或換行。
2. 模型字串是否與供應商可用名稱一致。
3. 若走 OpenAI 相容 API，`lm_api_url` 是否必填且可連線。
